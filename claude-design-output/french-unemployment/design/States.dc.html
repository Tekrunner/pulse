Specification · Every declared state

What each figure does when something is wrong

Nine states, each with a named word, an icon and a sentence a reader can act on. Colour never carries a state by itself.

ready

Value and represented period both render from the rows.

The baseline. Provenance and represented period are always present.

loading

Updating — showing Q2 2026 while the new quarter loads.

The previous render is held at reduced opacity — no skeleton flash, no layout jump.

empty

No observations in this window

No data for the chosen period. Widen the period or pick another quarter.

A legitimate answer, not an error: the query succeeded and matched nothing.

suspect

Check this figure. One provider value failed a plausibility check; the affected observation is marked in the table.

Usable data that failed a plausibility check. The figure still renders.

stale

Update overdue. Q3 2026 was expected by 21 Nov 2026 and has not arrived. Showing Q2 2026.

Derived from the clock at read time, never a stored string.

query-error

This figure could not load. The query did not complete. Other sections are unaffected.

The section fails alone; every other section keeps its data.

schema-incompatibility

This figure is out of date with its data. The published columns no longer match what this figure expects. It has been hidden rather than drawn from fields it cannot verify.

The dataset changed shape under the visual. Retrying cannot help, so nothing offers it.

render-error

This figure could not be drawn. The values are below as a table.

Q2 20268.3%
Q1 20268.1%

The visual threw while drawing. The accessible table still renders from the same rows.

shared-engine-failure

The data engine did not start. No figure on this page can load. The report header, sources and licences remain readable.

The one state that is report-wide: nothing can query, so the report says so once.
