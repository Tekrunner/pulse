Every state a figure can be in

Each state names itself in text and carries a second, non-colour cue: a glyph, a border treatment, or a skeleton. Colour is never the only signal. A figure that cannot draw keeps its accessible table, so the answer is still reachable.

Slot-local isolation: one figure fails, the report does not

Each figure owns its own query, its own validation and its own error boundary. A failure in one never blanks another, never clears the observation year, and never collapses an open disclosure elsewhere. The control row stays live so the reader can change the selection and the failed figure can retry into it.

What survives an asynchronous refresh

When a figure re-queries — because the period, the countries or the scenario changed — these are restored by stable identity, not by position: the focused control, the observation year, the scroll position, the open disclosures, and any partly typed custom range. A reader half way through setting a custom end year does not lose it because a figure finished loading.
