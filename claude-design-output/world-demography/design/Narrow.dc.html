Reflow rules this width fixes

Below 900px the control row stops being sticky and stacks: period, year, countries, projection, each full width. Small-multiple grids go to one column. Figures 2 and 5 follow figure 1's rule and figure 4 follows figure 3's, so they are not drawn again here.

The value strip keeps its place directly above each plot, exactly as at desktop. It wraps to more lines rather than shrinking, and it never moves into the plot: at this width a box over the marks would cover most of what it describes.

The country control keeps its 44px targets and wraps. The add-a-country select stays a native select so the platform's own picker does the work on a phone.

Nothing is dropped at this width: every figure, every band and every accessible table is still present. The page gets longer instead.
