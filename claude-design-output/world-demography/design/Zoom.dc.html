What 400% fixes

The page reflows to one column with no two-dimensional page scrolling. A figure is content that needs a two-dimensional layout, so it keeps a horizontal scroll inside its own frame; the reader never has to scroll the page sideways to read a sentence or reach a control.

Every figure's disclosure opens by default at this size. The table is the same data as the plot, so a reader who cannot use the plot at this magnification loses nothing.

Controls become full-width and stack vertically; the period presets become a vertical radio group. Targets stay at 44px. The control row is no longer sticky, because at this size it would take most of the viewport.

Text never shrinks below its base size to fit. The layout gets taller instead.
